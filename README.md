# Nexus Vault

Локальный менеджер паролей и защищённых заметок для Windows. Без регистрации и облака:
всё хранится на компьютере в зашифрованном виде (Argon2id + XChaCha20-Poly1305).
В сеть приложение ходит только за обновлениями (можно выключить) и, по кнопке, в проверку утечек паролей.

## Возможности

- Пароли, заметки в Markdown, банковские карты и документы; свои поля в любой записи
- Коды двухфакторной защиты (2FA, как в Google Authenticator) прямо в записи пароля
- Картинки и скриншоты в заметках (Ctrl+V, перетаскивание) — зашифрованы, как всё остальное
- История паролей: десять последних старых паролей у каждой записи
- Папки, теги, избранное, корзина; несколько хранилищ с быстрым переключением
- Проверка паролей: слабые, повторяющиеся, давно не менявшиеся и найденные в утечках
  (Have I Been Pwned: уходят только первые 5 символов хеша, не сами пароли)
- Вход по мастер-паролю или через Windows Hello (лицо, отпечаток, PIN)
- Мгновенный поиск (Ctrl+K), генератор паролей и парольных фраз
- Копирование в буфер с автоочисткой и без попадания в журнал Win+V
- Автоблокировка: по бездействию, при Win+L, при закрытии окна; работа из трея
- Глобальная клавиша Ctrl+Shift+L — открыть и сразу искать
- Зашифрованные резервные копии `.nexus`: вручную и автоматически по расписанию (только если что-то изменилось)
- Импорт из Bitwarden, Chrome, Edge, Firefox, KeePass, 1Password (CSV) и своего JSON; дубли пропускаются
- Экспорт в CSV (формат Bitwarden) и JSON; сброс хранилища, если мастер-пароль забыт
- Обновление в один клик из приложения
- Тёмная и светлая темы; интерфейс на русском

## Установка

Скачайте `Nexus.Vault_<версия>_x64-setup.exe` со страницы
[последнего релиза](https://github.com/STANFORDVIBE/nexus-vault/releases/latest) и запустите.
Дальше программа обновляется сама: «Настройки → О программе» или автопроверка раз в день.

Установщик на русском, ставится в профиль пользователя без прав администратора.
При удалении можно отметить «Удалить хранилища, автокопии и настройки» — по умолчанию
данные остаются.

## Разработка

Нужны Node.js 22+, Rust (stable, MSVC), Visual Studio Build Tools 2022 (C++ и Windows SDK).

```bash
npm install
npm run tauri dev
```

Проверки: `npm run check` (типы, линтеры, тесты фронтенда и Rust) и `npm run e2e`
(сценарии в Microsoft Edge). Интерфейс без Rust: `npm run dev` и открыть
`http://localhost:1420/?seed` — подключится фейковый бэкенд с тестовыми данными.
